# Noto Sans

`NotoSans-Regular.ttf` provient du dépôt officiel Noto Fonts :
https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf

Distribuée sous SIL Open Font License 1.1, reproduite dans `OFL.txt`.
Cette police est incorporée aux PDF pour conserver les accents et caractères internationaux.
Les polices de l'interface, Barlow et Rajdhani, sont fournies par leurs paquets Fontsource avec leurs licences.

Les PDF utilisent aussi Barlow Regular/SemiBold et Rajdhani SemiBold, incorporées depuis les fichiers TTF officiels de [Google Fonts](https://github.com/google/fonts/tree/main/ofl). Leurs licences SIL OFL 1.1 sont reproduites dans `Barlow-OFL.txt` et `Rajdhani-OFL.txt`.
